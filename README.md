# baobao

| 项目 | 内容 |
| --- | --- |
| [零售销量预测与库存仿真](retail-demand-inventory/) | 周销量预测、补货策略与库存成本比较 |
| [共享单车需求与站点流量分析](citibike-tide-and-dispatch/) | 骑行规律、小时需求预测与站点借还流量 |
| [道路交通事故严重性分析](road-safety-risk-analysis/) | 分组统计、逻辑回归与跨年评价 |
| [猜数字游戏](guess-number/) | 命令行交互与输入检查 |

## 运行

```bash
git clone https://github.com/baobao173/baobao.git
cd baobao
```

各项目的依赖和运行命令见对应目录的 README。数据分析项目使用 Python 3.12，猜数字游戏只依赖标准库。

## 文档与数据

分析报告和方法说明位于各项目的 `docs/`；图表和结果表位于 `output/` 或 `outputs/`。原始数据通过脚本下载，来源及使用条款见项目文档。
