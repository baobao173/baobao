## 关键真实数字（复现核对用）

- 数据：2019-05-01~08-31，8,575,221 → 8,564,754 行（99.88%），840 站；气象 2,952 小时（ERA5）。
- 检验：工作日日均 71,806 vs 周末 64,166（p<0.01）；时长 833s vs 1,021s（p<1e-12）。
- 潮汐：工作日净迁移 4,696 辆/日（周末 1,370）；站点 486 居住型 / 308 办公型 / 46 均衡。
- 归因：下雨 −41%/时；雨日 −20%；温度倒 U 顶点 25.8°C；R²=0.773。
- 预测：基线 MAE 818 → 岭 449 → 随机森林 270（R²=0.956），较基线改善 67%。
- 调度：投放窗口 5–7 点；Top 100 站覆盖 58%（失衡分散）。

## 复试问题清单（答案要点在 report.md §10 / CV_HIGHLIGHTS.md）

1. 为什么选共享单车这个问题？——分布式库存 + 运营决策，贴合"智能运营/管理科学"；
2. 数据从哪来？——Citi Bike System Data 官方一手 + Open-Meteo（ERA5），脚本可复现；
3. 潮汐怎么定义？——站点早高峰净流出 = 07–10 点借出 − 归还；
4. 怎么防数据泄漏？——滞后特征只用过去信息 + 按时间切分不打乱；
5. MAE=270 在业务上意味着什么？——约需求 9%，调度决策粒度可用；
6. 能推广到国内共享单车吗？——方法可迁移；无桩模式的桩位约束换成违停治理；
7. 最大局限？——无站点库存/桩位数据，故输出决策支持而非精确仿真；下一步接库存做线性规划优化。
