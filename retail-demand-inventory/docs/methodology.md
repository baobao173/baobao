# 方法说明

## 1. 样本与验证

按完整周补齐日历。训练期活跃周数/训练总周数≥0.8 的商品中，选正向销售额最高的 25 个。非交易周补零；这个处理不代表已验证营业和可售状态。

前 N-24 周训练、12 周验证、12 周测试。商品选择只在训练期完成；每个阶段开始用之前全部可用历史拟合，测试允许使用验证期历史。每周结束观察 actual 后，更新下周特征；阶段中模型系数不重训。测试后不重新选方案。

## 2. 预测

- naive：ŷ[t]=y[t-1]。
- moving_average：ŷ[t]=(y[t-1]+…+y[t-4])/4。
- ridge：X 为 lag1—4、前4周均值、前8周均值、前4周样本标准差。所有滚动计算先 shift(1)，最初8周没有完整特征，不能训练。

标准化仅在拟合样本估计。岭回归最小化 Σ(y-Xβ-b)²+αΣβ²，α=10 固定；不惩罚截距。不同商品单独拟合，避免量纲差异和混合商品解释。预测截到非负，没有把点预测当概率分布。

MAE=Σ|y-ŷ|/n；WAPE=Σ|y-ŷ|/Σy。测试整体 WAPE 受大销量商品影响，另给各商品误差表。由于每个商品样本周数相同，macro MAE 与总体 MAE 数值相同，不是独立证据。

## 3. 每周补货时序

周初：收到以前下单的货 → 查看手头与在途 → 计算目标 → 下单 → 零提前期立即到货 → 满足本周外生需求 → 记录缺货、期末库存和成本。

目标 S=ceil((L+1)×ŷ+k×σ×sqrt(L+1))。

订单 Q=max(0,S-手头库存-在途)。零提前期 L=0，L=1 时订单下一周初到。两周预测使用平坦外推，并没有读取下一周真实量。

σ 是本阶段开始前12周历史销量样本标准差，阶段内固定；不是预测残差标准差。k 是经验参数，不保证任何理论服务概率。平方根时间关系只是情景近似，未验证误差独立。

销量满足=min(库存,需求)，缺货=需求-满足，期末=可用库存-满足。缺货当期流失，不积压为欠单。所有策略每阶段从空库存空在途重新开始，无热身期。L=1 的第一周全缺货；其余周仍受启动影响。

成本=Σ期末库存+penalty×Σ缺货。每件每周持有成本归一化为1，penalty 为2/5/10。数量满足率=Σ满足/Σ需求；不等于无缺货周比例。平均库存定义为平均期末库存/商品周，不是周内时间加权库存。

## 4. 方案选择

A=移动平均 k=1；B=岭回归 k=1；C 在验证集的3模型×6系数中选情景成本最小组合（同成本按模型名、系数排序）。各 L/penalty 情景独立选一次，测试期锁定该组合。A/B隔离预测替换，C展示联合选择。图中的测试参数曲线仅描述权衡，不据此反向改变 C。

成本没有采购、固定订货、在途持有、终端残值，也没有共享仓容或采购预算。由于仿真需求是历史销量，不能评估真实缺货导致的需求丢失或客户流失。

## 5. 结果文件

| 文件 | 内容 |
| --- | --- |
| `predictions.csv` | 商品、周、阶段、实际销量和预测值 |
| `inventory_traces.csv` | 每周到货、订单、满足量与期末库存；运行主程序生成，不提交仓库 |
| `inventory_grid.csv` | 各模型和安全库存系数的情景结果 |
| `policy_comparison.csv` | 验证期选定策略在测试期的评价 |

测试覆盖手算补货案例、库存守恒、提前期、特征不读取当前/未来销量、模拟不读取未来需求。结果一致性检查命令为 `python scripts/verify_outputs.py`。
